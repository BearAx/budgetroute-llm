# Curated benchmark evidence

This directory contains small, reviewed result cards and machine-readable summaries for real runs. Raw predictions, caches, downloaded datasets, model weights, and ordinary generated output remain ignored under `outputs/` and `data/materialized/`.

Published evidence:

- [Qwen2.5 routing on stratified MMLU-100, RTX 3060 Laptop GPU](qwen25-mmlu-100-rtx3060.md)
- [Machine-readable summary](qwen25-mmlu-100-rtx3060.json)

Every card identifies the source commit, configuration and dataset hashes, exact model revisions, environment, uncertainty, and claim boundary. A result here is specific to its recorded setup; it is not a universal production or model-quality claim.
