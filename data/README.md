# Development data

`sample_benchmark.jsonl` and `sample_corpus/` are small, original development fixtures for exercising routing, evaluation, retrieval, and artifact generation. They contain no personal or proprietary data and are released under the repository MIT license.

They are not representative scientific benchmarks. Add external datasets through a dataset adapter and document their provenance, license, preparation, and limitations. Downloaded data and built indexes belong in ignored `data/downloads/` and `data/indexes/` directories.
