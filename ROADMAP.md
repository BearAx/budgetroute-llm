# Roadmap

Roadmap items are proposals, not completed features.

## v0.1 — functional benchmark and API

- Stabilize the fake/Transformers benchmark path and artifact schema.
- Validate the API and packaging across supported platforms.
- Run and publish reproducible real-model measurements separately from fake smoke outputs.

## v0.2 — datasets and calibration

- Add licensed public benchmark adapters and grouped split controls.
- Compare calibrated classifiers and threshold selection under distribution shift.
- Expand selective prediction and abstention analysis.

## v0.3 — scheduling and backends

- Add optimized dynamic batching and load-aware routing.
- Evaluate additional local inference runtimes behind the backend protocol.
- Expand quantization and compilation matrices with measured compatibility data.

## Future research

- Cost-aware multi-objective policies, online calibration, retrieval confidence, tail-latency constraints, and safe human-in-the-loop escalation.
