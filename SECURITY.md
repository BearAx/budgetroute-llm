# Security policy

Use GitHub private vulnerability reporting when it is enabled for this repository. If it is unavailable, open a minimal repository issue asking the maintainers for a private reporting channel; do not include exploit details, secrets, or personal data in a public issue.

Supported security fixes target the latest released minor version. This research software is not a security boundary: deployments must add authentication, authorization, rate limiting, TLS termination, audit controls, and model-safety policies appropriate to their environment.
